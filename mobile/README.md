# تطبيق «سُؤال AI» (Flutter — Android وiPhone)

تطبيق المدرس الكامل. يتصل بنفس خادم الموقع (`/api/v1`) بالحساب نفسه والبيانات نفسها: ما يعدّله المدرس في التطبيق يظهر في الموقع والعكس. على ويندوز والحاسوب يُستعمل الموقع.

## ما في التطبيق (نفس الموقع)
| الشاشة | المحتوى |
|---|---|
| الدخول | بريد/هاتف + كلمة مرور، رمز تحقق (أو رمزان مع «الأمان الإضافي»)، تذكّر الجهاز، نسيت كلمة المرور |
| إنشاء حساب | نفس حقول الموقع (المحافظة والمديرية من الخادم)، التحقق بالبريد أو SMS حين يتوفر، الموافقة على الشروط |
| امتحاناتي | القائمة وحالتها، فتح، حذف |
| جديد | المعالج: الصف ← المادة ← الكتاب، الفصول أو نطاق الصفحات، أنواع الأسئلة المسموحة للمادة بعددها ودرجتها، النوع والصعوبة والمدة، الدرجة الكلية والتوزيع، «بنفس هيكل امتحان سابق»، تنبيه النصوص الحرفية |
| المحرر | العنوان، المدة، الأسئلة الاختيارية (والأول إجباري)، توزيع الدرجات (ذكي/متساوٍ)، سؤال رئيس جديد يُولَّد، ولكل سؤال: التعليمة، الدرجة، الفروع الاختيارية، إضافة يدوية، توليد المزيد، نسخ، ترتيب، حذف؛ ولكل فرع: تعديل (النص والخيارات والإجابة والدرجة)، سؤال بديل، تراجع، نسخ، صورة، جدول، ترتيب، حذف؛ إظهار الإجابات |
| الورقة | معاينة PDF الحقيقية (محرّك الموقع نفسه)، طباعة مباشرة من الهاتف، مشاركة، الأسئلة/مع الإجابات/الإجابات النموذجية/ورقة إجابة الطالب، النماذج A–D، Word، ZIP لعدة نماذج ونسخ، الترويسة والقالب لكل امتحان |
| القوالب | قوالبي (إنشاء، تعديل كل الحقول، افتراضي، حذف)، نسخ قالب جاهز، الشعارات (رفع، حذف) |
| الحساب | الحالة، الأمان الإضافي، تسجيل الخروج، الشروط والخصوصية والتواصل، **حذف الحساب** |

يبقى في الموقع فقط: **الدفع والاشتراك** (سياسة المتاجر) و**لوحة الإدارة** (رفع الكتب وOCR والمناهج والموافقات).

## الدفع: من الموقع فقط
- لا سعر ولا زر دفع ولا رابط اشتراك ولا كلمة «اشتراك/دفع» داخل التطبيق؛ الحساب غير المفعّل يرى «حسابك غير مفعّل لهذه الخدمة.» (`errors.dart` يحوّل رموز SUBSCRIPTION_*/PAYMENT_* إليها، والاختبارات تتحقق).
- السبب: المتجران يأخذان عمولة على ما يُباع داخل التطبيق. **لا تضف ذلك** دون مراجعة سياسة المتجر الحالية؛ آبل قد تراجع تطبيقاً يعتمد على تفعيل خارجي، ويُحسم عند أول مراجعة.
- إنشاء الحساب موجود في التطبيق، لذلك **حذف الحساب** موجود أيضاً (شرط آبل).

## مصدر واحد للقوائم
`lib/catalog.g.dart` مولَّد من الموقع: أنواع الأسئلة وتعليماتها، حقول الترويسة، الخطوط، الألوان، أنواع الامتحان والصعوبة، **رسائل الأخطاء**، وحالات الحساب. بعد أي تعديل عليها في الموقع:
```
npx tsx scripts/gen-mobile-catalog.ts
```
(اختبار `src/lib/mobile-catalog.test.ts` يفشل إن نُسي.)

## التشغيل والاختبار
```
flutter pub get
flutter analyze && flutter test
flutter run --dart-define=API_BASE=https://النطاق
```
- `test/widget_test.dart`: الدخول والتبويبات والمحرر والإجراءات، وغياب أي ذكر للدفع.
- `test/small_screen_test.dart`: كل الشاشات على هاتف بعرض 360 بكسل بلا تجاوز.
- `test/live_server_test.dart`: كل عملية على خادم حي (`LIVE_TOKEN` و`LIVE_EXAM` و`LIVE_UNPAID`)؛ يتخطّى نفسه بدونها.

## النشر
- **Android:** `flutter build appbundle --dart-define=API_BASE=https://النطاق` ثم Google Play (حساب مطوّر 25$ مرة واحدة). وقّع التطبيق بمفتاح تحفظه بأمان، ولا ترفعه إلى GitHub.
- **iPhone:** يُبنى على Mac (أو خدمة بناء سحابية)، وحساب Apple Developer (99$ سنوياً). أضف في Info.plist وصف الوصول للصور (`NSPhotoLibraryUsageDescription`) — موجود.
- الإنتاج HTTPS فقط. الأيقونات من `brand/icon-full.svg` (`assets/icon.png` ثم `dart run flutter_launcher_icons`).
