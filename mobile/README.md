# تطبيق «سُؤال AI» (Flutter — Android وiPhone)

تطبيق المدرس. يتصل بنفس خادم الموقع عبر `/api/v1`، وبالحساب نفسه والبيانات نفسها. الموقع يبقى للتسجيل والدفع والإدارة.

## القرار: الدفع من الموقع فقط
- لا شاشة دفع ولا سعر ولا رابط اشتراك داخل التطبيق. حساب غير مفعّل يرى رسالة محايدة («حسابك غير مفعّل لهذه الخدمة»).
- السبب: متجرا آبل وجوجل يأخذان عمولة على كل ما يُباع داخل التطبيق. **لا تضف زر دفع أو رابطاً لصفحة الاشتراك في التطبيق** دون مراجعة سياسة المتجر الحالية؛ قد ترفض آبل تطبيقاً يوجّه للدفع الخارجي، وهذا يُحسم عند أول مراجعة.
- لا إنشاء حساب داخل التطبيق (التسجيل في الموقع)، فلا يُطلب حذف الحساب من داخله.

## المنجز
تسجيل الدخول (بريد/هاتف + كلمة مرور، ورمز OTP عند الطلب) مع حفظ الجلسة في التخزين الآمن · قائمة الامتحانات · عرض الامتحان مع إظهار/إخفاء الإجابات · تنزيل ومشاركة PDF وWord (الأسئلة، مع الإجابات، الإجابات النموذجية، ورقة الإجابة، النماذج A–D).

## الناقص (المراحل التالية)
معالج إنشاء امتحان جديد · تعديل الأسئلة والدرجات · القوالب والشعار · رمزان معاً عند «loginSecurity=BOTH» · نسخة iPad.

## التشغيل والاختبار
```
flutter pub get
flutter analyze && flutter test
flutter run --dart-define=API_BASE=https://النطاق
```
عنوان الخادم يُمرَّر وقت البناء. افتراضياً `http://10.0.2.2:3000` (محاكي أندرويد يصل لجهازك). على آيفون بالتجربة المحلية استعمل عنوان الشبكة.
اختبار على خادم حي: `LIVE_TOKEN=… LIVE_EXAM=… LIVE_UNPAID=… flutter test test/live_server_test.dart`.

## النشر
- **Android:** `flutter build appbundle --dart-define=API_BASE=https://النطاق` ← يُرفع إلى Google Play (حساب مطوّر 25$ مرة واحدة). يلزم توقيع التطبيق بمفتاح تحتفظ به بأمان (لا يُرفع إلى GitHub).
- **iPhone:** يُبنى على جهاز Mac فقط (أو خدمة بناء سحابية)، ويلزم حساب Apple Developer (99$ سنوياً).
- ملفات الأيقونات مولَّدة من `brand/icon-full.svg` (`assets/icon.png` ثم `dart run flutter_launcher_icons`).
- الإنتاج يجب أن يكون HTTPS (أندرويد يمنع HTTP الصريح في النسخ النهائية).
